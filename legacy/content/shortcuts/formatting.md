## Shortcuts

| Action | Windows | macOS | Sheets |
| --- | --- | --- | --- |
| Make the text bold | `Ctrl + B` | `Command + B` | `Ctrl + B` |
| Make the text italic | `Ctrl + I` | `Command + I` | `Ctrl + I` |
| Underline the text | `Ctrl + U` | `Command + U` | `Ctrl + U` |
| Strike through the text | `Ctrl + 5` | `Command + Shift + X` | `Alt + Shift + 5` |
| Open the Format Cells dialog | `Ctrl + 1` | `Command + 1` | `No default` — Format ▸ Number |
| Apply a two-decimal number format | `Ctrl + Shift + 1` | `Control + Shift + 1` | `Ctrl + Shift + 1` |
| Apply a time format | `Ctrl + Shift + 2` | `Control + Shift + 2` | `Ctrl + Shift + 2` |
| Apply a date format | `Ctrl + Shift + 3` | `Control + Shift + 3` | `Ctrl + Shift + 3` |
| Apply a currency format | `Ctrl + Shift + 4` | `Control + Shift + 4` | `Ctrl + Shift + 4` |
| Apply a percentage format | `Ctrl + Shift + 5` | `Control + Shift + 5` | `Ctrl + Shift + 5` |
| Apply a scientific format | `Ctrl + Shift + 6` | `Control + Shift + 6` | `Ctrl + Shift + 6` |
| Go back to the General format | `Ctrl + Shift + ~` | `Control + Shift + ~` | `No default` — Format ▸ Number ▸ Automatic |
| Fill the cell below from the cell above | `Ctrl + D` | `Command + D` | `Ctrl + D` |
| Fill the cell to the right from the cell on the left | `Ctrl + R` | `Command + R` | `Ctrl + R` |

## When to use it

The keyboard wins on the formats you can see at a glance. A column of ratios arrives as `0.0714`, and
`Ctrl + Shift + 5` makes it `7.14%` in one press. No dialog opens and no decimals are lost. If you open
the Format Cells dialog every day, the six `Ctrl + Shift` number formats are the fastest minute you will
get back.

`Ctrl + D` and `Ctrl + R` are the fill keys, and they copy from the cell above or to the left. That
matters when you have typed a formula whose references were chosen for dragging, because a fill down
adjusts relative references the same way the fill handle does.
