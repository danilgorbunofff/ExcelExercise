## Shortcuts

| Action | Windows | macOS | Sheets |
| --- | --- | --- | --- |
| Move the active cell one cell in any direction | `Arrow keys` | `Arrow keys` | `Arrow keys` |
| Jump to the edge of the block of data | `Ctrl + Arrow key` | `Command + Arrow key` | `Ctrl + Arrow key` |
| Go to the last cell that holds data | `Ctrl + End` | `Command + End` — Fn + Command + Right Arrow on a laptop | `Ctrl + End` |
| Return to the top left corner | `Ctrl + Home` | `Command + Home` — Fn + Command + Left Arrow on a laptop | `Ctrl + Home` |
| Move one screen down | `Page Down` | `Page Down` | `Page Down` |
| Move one screen right | `Alt + Page Down` | `Option + Page Down` | `No default` — drag the scrollbar instead |
| Move one screen left | `Alt + Page Up` | `Option + Page Up` | `No default` — drag the scrollbar instead |
| Jump to the next worksheet | `Ctrl + Page Down` | `Option + Right Arrow` | `No default` — click the tab instead |
| Jump to the previous worksheet | `Ctrl + Page Up` | `Option + Left Arrow` | `No default` — click the tab instead |
| Go to a cell you name | `Ctrl + G` | `Ctrl + G` | `No default` — type the address in the Name box |
| Move to column A of the current row | `Home` | `Home` | `Home` |
| Move to the last cell of the current row | `End` | `End` | `No default` — Ctrl + Right Arrow stops at the end of the block |

## When to use it

Reach for these before you touch the scrollbar. A sheet with four thousand rows is mostly empty below
the data, so scrolling lands you in blank space. `Ctrl + Arrow` stops at the last cell that holds
something.

The trip that surprises people is a sheet imported from another tool. A column arrives with trailing
spaces in some rows, and `Ctrl + Down` stops early at the row where those spaces begin. If you land
somewhere unexpected, look for a cell that looks empty and is not.
