## Shortcuts

| Action | Windows | macOS | Sheets |
| --- | --- | --- | --- |
| Hide or show the ribbon | `Ctrl + F1` | `Command + Option + R` | `No default` — View ▸ Show ribbon |
| Freeze the rows above the active cell | `Alt + W + F + F` | `No default` — View ▸ Freeze Panes | `No default` — View ▸ Freeze |
| Split the window at the active cell | `Alt + W + S` | `No default` — View ▸ Split | `No default` — View ▸ Split |
| Open the zoom dialog | `Alt + W + Q` | `No default` — View ▸ Zoom | `No default` — View ▸ Zoom |
| Switch to the next open workbook | `Ctrl + Tab` | `Command + Grave` | `No default` — click the tab |
| Cycle back through the open workbooks | `Ctrl + Shift + Tab` | `Command + Shift + Grave` | `No default` — click the tab |
| Open a second window on the same workbook | `Alt + W + N` | `No default` — Window ▸ New Window | `No default` — there is nothing to open |
| Move to the next pane of a split window | `F6` | `F6` | `No default` — click the pane |
| Close the workbook window | `Ctrl + W` | `Command + W` | `No default` — the browser tab closes |
| Rename the current worksheet | `Alt + H + O + R` | `No default` — Format ▸ Sheet ▸ Rename | `No default` — double-click the tab |
| Hide the current worksheet | `Alt + H + O + H` | `No default` — Format ▸ Sheet ▸ Hide | `No default` — right-click the tab |

## When to use it

Frozen panes are the only item here that changes how you read a sheet rather than where you are in it.
Freezing the header row keeps the column names in view when you scroll to row 900.
`Alt + W + F + F` freezes everything above the cell you are on, so put the cursor in the first data row
before you press it.

The rest is housekeeping for a workbook with many tabs. Once there are more sheets than fit across the
bottom of the window, `Ctrl + Page Down` moves through them in order. That is faster than hunting for a
tab that scrolled out of sight.
